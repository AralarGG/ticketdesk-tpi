## Problema

Las empresas que brindan soporte a clientes (por ejemplo, equipos de atención al usuario en productos de software o videojuegos) necesitan un sistema centralizado para registrar, categorizar y dar seguimiento a los reclamos o consultas de los usuarios, evitando que se pierdan solicitudes o se dupliquen esfuerzos entre agentes.

## Alcance

- Alta de tickets por parte de usuarios (título, descripción, categoría, prioridad)
- Asignación de tickets a agentes de soporte
- Cambio de estado del ticket (abierto, en progreso, resuelto, cerrado)
- Listado y filtrado de tickets por estado/prioridad/agente
- Panel de administración básico para agentes
- Autenticación simple de usuarios (usuario/agente)

## Stack Tecnológico

- **Backend:** Java 21 + Spring Boot + JPA
- **Frontend:** React + TypeScript
- **Base de datos:** PostgreSQL
- **Despliegue:** Backend en Render/Railway, Frontend en Vercel/Netlify

## Estructura del Repositorio
